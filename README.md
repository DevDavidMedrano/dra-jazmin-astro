# Sitio web - Dra. Jazmín Álvarez

Primera versión de la portada construida con Astro y preparada para publicarse en Vercel.

## Iniciar en local

```powershell
npm install
npm run dev
```

Abre `http://localhost:4321`.

## Compilar

```powershell
npm run build
```

## Estructura principal

- `src/pages/index.astro`: página de inicio.
- `src/components`: encabezado, portada, tarjetas y secciones.
- `src/layouts/BaseLayout.astro`: metadatos y estructura HTML.
- `src/styles/global.css`: diseño responsive y paleta de marca.
- `public/brand`: logotipo y símbolo.
- `public/images/hero-doctor.webp`: imagen temporal de referencia.

## Importante

La imagen de la doctora se obtuvo de la referencia visual proporcionada y debe sustituirse por una fotografía oficial antes de publicar el sitio. El número de WhatsApp y la ubicación se tomaron del brandboard; conviene confirmarlos con la doctora.
